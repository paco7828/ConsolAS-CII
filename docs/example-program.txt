# Program welcome messages
Settings loaded from config.properties
Consolas-CII - console schematic builder - type 'help' or 'exit'


# Get to know the available commands
> help
add <R|C|L> <value>                     e.g. add R 50k | add resistor 50k | add C 100n
add <D|LED|TP4056|MT3608|AMS1117-x>      no value, e.g. add LED | add TP4056 | add AMS1117-3.3
                                         (AMS1117-x: 1.2 1.5 1.8 2.5 2.85 3.3 5.0 ADJ)
connect <pin|net> <pin|net>              e.g. connect R1.1 U1.VIN | connect C1.2 GND | connect LED1.ANODE VCC(5V)
disconnect <pin>                         e.g. disconnect R1.1
remove <ref>                             e.g. remove R1
rename net <old-name> <new-name>         e.g. rename net N1 VIN
draw [ref]                               draw the whole schematic, or only one part (draw U1)
show pins <ref>                          pins of a part and what they are connected to
components [sort ref|type|value]         list the parts
nets                                     list the nets
run drc                                  design rule check: look for problems in the circuit
analyze <ref> <args>                     e.g. analyze U1 5 200m (input voltage, load current)
clear | cls                              clear the screen
rename circuit <new-name>                e.g. rename circuit My charger
circuits                                 list saved circuits
new <name> | save | load <name> | help | exit
